# 🔐 Password Generator

A simple and secure **Python-based Password Generator** that generates strong, random passwords using uppercase letters, lowercase letters, numbers, and special characters.

## 🚀 Features

- 🔑 Generates strong random passwords
- 🔢 Includes numbers
- 🔤 Includes uppercase and lowercase letters
- 🔣 Includes special characters
- ⚡ Fast and easy to use
- 🐍 Built completely using Python

## 🛠️ Technologies Used

- **Python**
- `random` module
- `string` module

## 💡 How It Works

The program combines different types of characters:

- Uppercase letters: `A-Z`
- Lowercase letters: `a-z`
- Numbers: `0-9`
- Special characters: `! @ # $ % ^ & *`

It randomly selects characters and creates a strong password based on the required length.

## 📌 Example

```text
Enter password length: 12

Generated Password: X7@kP2!mQ9#z
```

> ⚠️ The generated password is an example. For real accounts, use a unique password for each service and store it securely.
